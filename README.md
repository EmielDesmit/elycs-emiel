# Elycs Emiel — portfolio website

Static website (HTML/CSS/JS) built from the Figma design **WEBSITE ELYCS EMIEL**.

- `index.html` — home: hero, project overview, Wasted Paris, Cadavre Exquis, The Common, Artist Release, press studio shoots
- `about.html` — biography, software, clients
- `contact.html` — contact details, disciplines
- `css/style.css` — all styling (desktop layout based on the 1512px Figma frame, responsive for tablet and mobile)
- `js/main.js` — drag-to-scroll for the "swipe" carousels
- `img/` — images exported from Figma
- `video/` — web-optimised videos (muted, autoplay on scroll)

## Live
Hosted with GitHub Pages: `https://<github-username>.github.io/elycs-emiel/` (Settings → Pages → Deploy from branch `main`, folder `/ (root)`).

Contact: Elycswork@gmail.com

## Editing
Edit the HTML files directly; replace images in `img/` with the same filename to swap a photo.
Fonts: Julius Sans One + Karla (Google Fonts). Futura is used when installed, otherwise Jost.
